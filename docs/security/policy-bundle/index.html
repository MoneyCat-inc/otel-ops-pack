🔒 Policy Bundle & Cosign Attestations

Enforce guardrails with signed OPA bundles and supply-chain verification.

What This Provides

  • OPA Policy Bundle — Rego rules for config validation, security policies, and compliance checks
  • Cosign Attestations — Cryptographically signed artifacts with keyless verification
  • Supply-Chain Security — Verify policy bundles before deployment
  • Audit Trail — Every policy change is signed and traceable

Verification Example

# Verify signed policy bundle
cosign verify --certificate-identity-regexp=".*" \
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  ghcr.io/moneycat-inc/policy-bundle:latest

# Download and extract bundle
opa run \
  --server \
  --bundle https://hub.resonai.uk/security/policy-bundle/bundle.tar.gz
