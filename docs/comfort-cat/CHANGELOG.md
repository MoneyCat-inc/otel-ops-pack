## Version Format

- **cc-v1.2.0** - Comfort Cat version 1.2.0
- **MAJOR** - Breaking changes to guidelines structure or philosophy
- **MINOR** - New guidelines, significant additions, process improvements
- **PATCH** - Bug fixes, clarifications, minor updates

## Change Types

- **Added** - New guidelines, processes, or features
- **Changed** - Modifications to existing guidelines or processes
- **Deprecated** - Guidelines marked for removal in future versions
- **Removed** - Guidelines removed in this version
- **Fixed** - Bug fixes in guidelines or processes
- **Security** - Security-related changes or improvements
