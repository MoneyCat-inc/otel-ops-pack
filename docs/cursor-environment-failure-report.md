# 📝 Cursor Environment Failure Report

**Reporter:** OTel Observability Copilot  
**Date:** January 2025  
**Environment:** Windows 11, Cursor (latest build)  
**Issue Type:** Environment/Network Configuration  

---

## 🚨 Summary

Cursor's diagnostic tool consistently stalled on **DNS/HTTP2/SSL tests** and **agents/Codex plugins would not respond**.

**Root cause:** Combination of deprecated API endpoint, proxy interference, and extension host crashes.

---

## 🔍 Symptoms Observed

- ❌ Diagnostic tool hung at DNS/HTTP2/SSL tests
- ❌ Agents and Codex would not load or respond
- ❌ DevTools console errors:
  - `Extension host (LocalProcess ...) terminated unexpectedly`
  - `Timeout waiting for EverythingProvider`
- ❌ PowerShell network tests showed:
  - `nslookup api.cursor.sh` returned only name, no IP
  - `curl.exe` revealed proxy interference: `Uses proxy env variable https_proxy == 'http://127.0.0.1:8888'`

---

## 🔧 Root Causes Identified

### 1. **Deprecated API Endpoint**
- Cursor calling `api.cursor.sh` (no A record in DNS)
- Current working hosts: `api.cursor.com` and `api2.cursor.sh`

### 2. **Proxy Interference** 
- HTTPS requests silently redirected through `127.0.0.1:8888`
- Lingering environment variables: `HTTPS_PROXY`, `HTTP_PROXY`

### 3. **Extension Host Crashes**
- Stale state files in `%APPDATA%\Cursor\User\globalStorage`
- "EverythingProvider" search integration timeouts blocking startup

---

## ✅ Resolution Steps Applied

### Network Fix
```powershell
# Clear proxy environment variables
$env:HTTPS_PROXY = $null
$env:HTTP_PROXY = $null

# Kill process on 127.0.0.1:8888
netstat -ano | findstr :8888
taskkill /PID <PID> /F

# Switch to reliable DNS
netsh interface ip set dns "Wi-Fi" static 1.1.1.1
netsh interface ip add dns "Wi-Fi" 8.8.8.8 index=2

# Temporary HOSTS workaround
echo "104.21.0.0 api.cursor.sh" >> C:\Windows\System32\drivers\etc\hosts
```

### Extension Host Fix
```powershell
# Launch Cursor in safe mode
cursor --disable-extensions

# Clear stale state files
Remove-Item "$env:APPDATA\Cursor\User\globalStorage\state.vscdb*" -Force
Remove-Item "$env:APPDATA\Cursor\User\workspaceStorage\*" -Recurse -Force
```

### Verification
```powershell
# Test API endpoints
curl.exe -Iv https://api.cursor.com/
curl.exe -Iv https://api2.cursor.sh/

# Verify Cursor diagnostics pass
# Check agents/Codex responsiveness
```
