### MEMX Architecture Recommendations

## 1. **Scope of Coverage**

**Recommended: Hybrid Approach**
- **Primary**: Browser-level memory flows (WASM, SAB, AudioWorklets, IndexedDB)
- **Secondary**: System-level transfers (RAM↔VRAM via existing GPU monitoring)
- **Exclude**: Pagefile activity, DMA (not accessible from browser)

**Rationale**: Browser-level memory is most relevant for Resonai's audio processing pipeline, while system-level monitoring can leverage existing GPU infrastructure.

## 2. **Granularity**

**Recommended: Dual-Granularity**
- **Per-Frame**: Critical audio processing (128-frame quanta, 60fps HUD)
- **Session-Level**: Broader memory patterns and trends

**Implementation**:
```typescript
// Per-frame (high frequency)
interface FrameMemoryMetrics {
  wasmHeapSize: number;
  sabBufferUsage: number;
  audioWorkletMemory: number;
  timestamp: number;
  frameId: string;
}

// Session-level (aggregated)
interface SessionMemoryMetrics {
  peakMemoryUsage: number;
  averageMemoryUsage: number;
  memoryLeaks: number;
  gcEvents: number;
  sessionDuration: number;
}
```

### Technical Specifications

## Memory Metrics Schema

```typescript
interface MemxMetrics {
  // Core metrics
  wasmHeapSize: number;           // WASM memory usage
  sabBufferUsage: number;         // SharedArrayBuffer usage
  audioWorkletMemory: number;     // AudioWorklet memory
  indexeddbUsage: number;         // IndexedDB storage
  
  // System metrics (via existing GPU monitoring)
  gpuMemoryUsage: number;         // VRAM usage
  systemMemoryUsage: number;      // System RAM usage
  
  // Performance metrics
  gcEvents: number;               // Garbage collection events
  memoryLeaks: number;            // Detected memory leaks
  performanceScore: number;       // Overall memory performance
  
  // Metadata
  timestamp: number;
  sessionId: string;
  frameId?: string;
  variant: 'frame' | 'session';
}
```

## SigNoz Queries

```sql
-- Memory usage trends
SELECT timestamp, wasmHeapSize, sabBufferUsage 
FROM logs 
WHERE dataset = 'resonai_analytics' 
  AND event = 'memory_observation'
  AND timestamp >= now() - INTERVAL 1 HOUR

-- Memory leak detection
SELECT sessionId, count(*) as leakCount
FROM logs 
WHERE dataset = 'resonai_analytics' 
  AND event = 'memory_observation'
  AND memoryLeaks > 0
GROUP BY sessionId

-- Performance correlation
SELECT avg(wasmHeapSize), avg(ttv_ms)
FROM logs 
WHERE dataset = 'resonai_analytics' 
  AND event IN ('memory_observation', 'audio_processing')
  AND timestamp >= now() - INTERVAL 1 HOUR
```
