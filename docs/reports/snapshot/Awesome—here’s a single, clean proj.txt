# 📊 Resonai Project — Unified Snapshot (2025-09-27)

## 🎯 Mission & Goals

Resonai is a **local-first, privacy-preserving voice feminization trainer**. The vision is to provide affirming, accessible training through:

1. **Inclusive UX & Curriculum** — gender-affirming onboarding, adaptive lesson flows.
2. **Real-Time Audio Feedback** — pitch, resonance, prosody, expressiveness.
3. **Local-First Architecture** — IndexedDB storage, no cloud uploads, strict CSP/COOP/COEP.
4. **Production-Grade Reliability** — CI/CD guardrails, automated testing, agent maintenance.

---

## 🏗 System Architecture

* **Frontend**: Next.js 14, React 18, TailwindCSS, Radix UI.
* **Audio Processing**:

  * Pitch — CREPE-tiny ONNX via WASM + YIN fallback.
  * Resonance — LPC / formant proxy + spectral centroid.
  * Prosody — rise/fall classifier + expressiveness metric.
* **Persistence**: IndexedDB (Dexie) with flow/session JSON.
* **Security**: Strict CSP, cross-origin isolation in Firefox & Chrome.
* **Ops**: Vercel deployment, Playwright E2E, GitHub Actions CI, Windows PowerShell scripts.
* **Host Machine**: Windows 11 Pro, Ryzen 3900X, RTX 2080 Super, 32 GB RAM.
