# SBOM Audit Procedure

**Authority**: BossCat OEM — Supply Chain Integrity  
**Purpose**: Verify SBOM and signature registry integrity for compliance

---

## Overview

SBOM (Software Bill of Materials) artifacts are generated during prod gate runs and uploaded with SHA256 checksums for integrity verification.

**Artifacts Location**: GitHub Actions artifacts (90-day retention)  
**Naming**: `sbom-attestation-<run_number>`

---

## Verification Steps

### 1. Download SBOM Artifacts

**Via GitHub UI**:
1. Navigate to https://github.com/MoneyCat-inc/otel-ops-pack/actions
2. Find latest prod gate run (workflow: "BossCat — Gate Verify")
3. Download artifact: `sbom-attestation-<run_number>`

**Via GitHub CLI**:
```bash
# List recent prod gate runs
gh run list --repo MoneyCat-inc/otel-ops-pack \
  --workflow bosscat-gate-verify.yml \
  --limit 5

# Download artifact from specific run
gh run download <run_id> \
  --repo MoneyCat-inc/otel-ops-pack \
  --name sbom-attestation-<run_number>
```

---

### 2. Verify SBOM Integrity

**Location**: `DELT/ARTF/sbom.json`  
**Checksum**: `DELT/ARTF/sbom.json.sha256`

```bash
# Navigate to artifact directory
cd sbom-attestation-<run_number>

# Verify SBOM integrity
sha256sum -c DELT/ARTF/sbom.json.sha256

# Expected output:
# DELT/ARTF/sbom.json: OK
```

---

### 3. Verify Signature Registry Integrity

**Location**: `DELT/ARTF/sbom/signature-registry.json`  
**Checksum**: `DELT/ARTF/sbom/signature-registry.json.sha256`

```bash
# Verify signature registry integrity
sha256sum -c DELT/ARTF/sbom/signature-registry.json.sha256

# Expected output:
# DELT/ARTF/sbom/signature-registry.json: OK
```

---

### 4. Inspect SBOM Contents

```bash
# Pretty-print SBOM
jq . DELT/ARTF/sbom.json | less

# Check component count
jq '.components | length' DELT/ARTF/sbom.json

# List dependencies
jq '.components[] | {name: .name, version: .version}' DELT/ARTF/sbom.json
```

---

## Expected Artifacts

Each `sbom-attestation-<run_number>` artifact contains:

```
DELT/ARTF/
├── sbom.json                                 # CycloneDX SBOM (generated by Syft)
├── sbom.json.sha256                          # SHA256 checksum for integrity verification
└── sbom/
    ├── signature-registry.json               # Code signature registry
    └── signature-registry.json.sha256        # SHA256 checksum for registry
```

---

## Compliance Checklist

For audit compliance, verify:

- [ ] SBOM artifact exists for prod gate run
- [ ] Artifact retention is 90 days (compliance requirement)
- [ ] SHA256 checksums verify successfully
- [ ] SBOM contains expected components (dependencies)
- [ ] Signature registry is present
- [ ] All checksums match (no tampering)
- [ ] Artifacts are timestamped correctly
- [ ] Run corresponds to prod promote (not ci/local)

---

## Troubleshooting

**Issue**: Checksum verification fails  
**Cause**: File modified or corrupted  
**Action**: Re-download artifact or trigger new prod gate run

**Issue**: SBOM missing from artifact  
**Cause**: Generation failed or path issue  
**Action**: Check CI logs for SBOM generation step, verify tooling

**Issue**: Artifact not found  
**Cause**: Retention period expired or wrong run ID  
**Action**: Verify run ID, check if within 90-day window
