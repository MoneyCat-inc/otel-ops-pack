🪟 Windows Service Mode (NSSM)

Production deployment pattern for OpenTelemetry Collector on Windows.

Why NSSM?

NSSM (Non-Sucking Service Manager) provides robust service management for the OTel Collector on Windows, including automatic restart, log rotation, and proper shutdown handling.

Installation

# Download NSSM
# https://nssm.cc/download

# Install OTel Collector as service
nssm install otelcol-contrib "C:\Program Files\otelcol-contrib\otelcol-contrib.exe" --config="C:\otel\config\config.yaml"

# Configure service
nssm set otelcol-contrib AppDirectory "C:\otel"
nssm set otelcol-contrib DisplayName "OpenTelemetry Collector"
nssm set otelcol-contrib Description "Production telemetry collection for Windows"
nssm set otelcol-contrib Start SERVICE_AUTO_START

# Start service
nssm start otelcol-contrib

# Verify
sc query otelcol-contrib

Management

# Stop service
nssm stop otelcol-contrib

# Restart service
nssm restart otelcol-contrib

# Remove service
nssm remove otelcol-contrib confirm
