# Resonai · Social Policy (Bluesky / SOCM lane)

Tone: calm, curious, receipts‑first. No dunking. Link sources. Prefer “here’s what we tested” over “gotcha”.
Safety: never share sensitive data. If in doubt, don’t post. Respect platform rules and the project’s Code of Conduct.

**Golden rules**
1) Evidence before claims. Always link to the public evidence page when possible.
2) Be precise: avoid speculation; state what is known and unknown.
3) Accessibility: every image must have alt‑text (1‑line “what this shows”).
4) Use at most 2 relevant tags (see TAGS.yaml). No tag spam.
5) Conflict of interest: disclose relationships when relevant.

**Kill‑switch**
If `.agent/LOCK` exists, all social automation must stop immediately (human only).
