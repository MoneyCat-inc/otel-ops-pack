### POST-002: Method Thread (Tuesday Deep-Dive)

**Text (1/3):**
```
🔍 How to spot a misleading claim in 60 seconds

Our 3-question filter:

1️⃣ "Who benefits if I believe this?"
2️⃣ "Is the source verifiable?" (name + link test)
3️⃣ "Does this match *two* independent outlets?"

If it fails #2 or #3 → flag as "needs context."

🧵 Thread (1/3)

#AntiClickbait #MediaLiteracy
```

**Text (2/3):**
```
Why two sources?

Single-source claims often turn out to be:
• Misattributed quotes
• Out-of-context video
• Genuine but exaggerated

Two *independent* outlets = claim passed basic editorial checks.

Example: AFP + Reuters both debunk → safe to cite.

(2/3)
```

**Text (3/3):**
```
Where to check:

• @fullfact.org (UK)
• @factcheck.afp.com (global)
• @politifact.bsky.social (US)
• @reuters.com (breaking)

Or search "[claim] fact check" on Bluesky.

Full method + tools: https://hub.resonai.uk/

(3/3) #FactCheck
```

**Engagement Hook:** Ask in final reply: "What's your go-to verification shortcut? Drop it below."

## 💬 Reply Macros (10)

Use these as quick responses to common engagement scenarios:

### REPLY-001: CHECKLIST Request

**Trigger:** Anyone replies "CHECKLIST" or asks "How do I verify?"

**Response:**
```
🔍 Verification Checklist

Before sharing a claim:

□ Two independent sources confirm it
□ Original source is named + linked
□ Date/context is clear (not old news)
□ Images reverse-search clean
□ Emotional language flagged

Full guide: https://hub.resonai.uk/

#AntiClickbait
```

---

### REPLY-002: Source Request

**Trigger:** Someone asks "Where's the source?"

**Response:**
```
Good catch! Here are the sources:

1. [Source 1 name + link]
2. [Source 2 name + link]

We always cite *two* independent outlets before calling something verified.

Full method: https://hub.resonai.uk/
```

---

### REPLY-003: Disagreement (Polite)

**Trigger:** Someone disputes your verification

**Response:**
```
Thanks for the feedback! Open to correction.

Can you share:
• The contradicting source (link?)
• Why you think it's more reliable?

If you have better evidence, I'll update the thread. We're evidence-first, not ego-first. 🐾
```
