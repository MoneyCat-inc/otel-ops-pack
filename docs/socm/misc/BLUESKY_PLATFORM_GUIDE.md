## ✍️ POSTING FEATURES

### **Post Composer** (Click "New Post")

**Capabilities**:
- **Text**: 300 character limit
- **Images**: Up to 4 images per post
- **Videos**: Upload videos
- **Alt text**: Add image descriptions
- **Links**: Auto-preview link cards
- **Mentions**: @username
- **Hashtags**: #tag (discoverable)
- **Threads**: Reply to your own post to create thread
- **Quote posts**: Embed another post in yours
- **Polls**: (May be available depending on features)

**Post Settings**:
- Who can reply (Everyone, Following, Mentioned, Nobody)
- Labels (self-applied content warnings)
- Thread settings

**Drafts**:
- Posts are auto-saved as drafts
- Can return to unfinished posts

- Total posts count

### **NOT Available** (Unlike other platforms):

- No built-in analytics dashboard
- No follower growth graphs
- Simpler, less commercial approach

## 🎨 UNIQUE BLUESKY FEATURES

### **1. Custom Feeds**
- Create algorithmic feeds using code
- Subscribe to community feeds
- Publish feeds for others
- Example: "OpenTelemetry mentions" feed

### **2. Starter Packs**
- Curated collections of accounts
- Help new users find relevant people
- Example: "Observability Experts" pack

### **3. Domain Handles**
- Can use your own domain as handle
- Example: Could be `@resonai.otel` or `@otel-ops-pack.com`
- Shows verified ownership

### **4. Decentralized Protocol**
- Built on AT Protocol
- Can self-host (advanced)
- Data portability
- No algorithmic manipulation

### **5. Labelers**
- Third-party moderation services
- Subscribe to community standards
- Customize content filtering
