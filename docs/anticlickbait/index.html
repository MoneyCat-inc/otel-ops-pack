What This Is

An inventory of what this project actually does. Each card shows:

  • Score (0-100) based on evidence quality

Scoring: 100 = perfect evidence | 90-99 = excellent | 80-89 = good | <80 = needs work

Scoring Methodology

Version: anticlickbait-v1

Criteria

  1. Verifiable evidence (source links, artifacts)
  2. Honest limitations disclosed
  3. No exaggerated claims
  4. Reproducible results
  5. Transparent methodology

Scale

  • 100: Perfect transparency, complete evidence trail
  • 90-99: Excellent evidence, only minor gaps
  • 80-89: Good evidence, some limitations acknowledged
  • 70-79: Adequate evidence, notable limitations
  • <70: Insufficient evidence or concerning gaps
