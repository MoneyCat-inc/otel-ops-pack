# Getting Started

## Installation

```bash
git clone https://github.com/MoneyCat-inc/otel-agent-coordination.git
cd otel-agent-coordination
pip install -e .
```

## Prerequisites

1. **OpenTelemetry Collector**: Running on localhost:4317
2. **Telemetry Backend**: SigNoz (recommended) or Jaeger
3. **Python**: 3.9 or higher
