# Getting Started with otel-agent-coordination

## Installation

```bash
pip install otel-ops-pack
```

## Quick Start

1. Set up OpenTelemetry Collector
2. Configure telemetry backend (SignOz recommended)
3. Initialize coordinator in your agents
4. Emit and query telemetry for coordination
