=== Manual Import Commands ===

# Import via PowerShell
$alerts = Get-Content 'artifacts/signoz-gpu-alerts.json' | ConvertFrom-Json
foreach ($alert in $alerts.alerts) {
    $body = $alert | ConvertTo-Json -Depth 3
    Invoke-WebRequest -Uri 'http://localhost:8080/api/v1/alerts' -Method Post -Body $body -ContentType 'application/json'
}

=== Verification ===

After import, verify alerts in SigNoz:
- Go to Alerts → List
- Filter by tag: gpu
- Check alert status: Active/Inactive
