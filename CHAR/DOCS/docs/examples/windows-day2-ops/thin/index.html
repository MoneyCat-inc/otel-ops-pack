🪟 Thin Example — Collector-only (Windows)

Minimal, vendor-neutral Day-2 guardrails with stock OpenTelemetry Collector.

What's Included

  • Stock OTel Collector config - Windows Event Logs + file logs to OTLP export
  • NSSM service wrapper — Install/uninstall scripts for production deployment
  • CI snippet — Policy gate + SBOM generation in GitHub Actions
  • No external dependencies — Self-contained, works with any OTLP backend

Quick Start

# Clone the kit
git clone https://github.com/MoneyCat-inc/otel-ops-pack.git
cd otel-ops-pack

# Review the collector config
cat config/otel-collector-config.yaml

# Install as Windows service
pwsh scripts/install-service.ps1

# Verify
sc query otelcol-contrib

Key Features

  • ✅ Windows Event Log collection (Security, Application, System)
  • ✅ File log tailing (custom app logs)
  • ✅ Low-latency batching (200ms)
  • ✅ Noise filtering (~50% volume reduction)
  • ✅ OTLP export (gRPC or HTTP)
  • ✅ Service management (NSSM)
