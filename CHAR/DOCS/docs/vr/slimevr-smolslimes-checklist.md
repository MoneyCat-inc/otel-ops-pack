# SlimeVR + Smol Slimes V2-Q + Quest 3 — Quick Checklist

Use after Windows updates, USB changes, SlimeVR updates, or “why is my body twisted” moments.

---

## Pre-flight

- [ ] PC on, Quest 3 charged
- [ ] 6× Smol Slimes V2-Q charged (≥50%)
- [ ] 3× nRF52840 dongles (E104-BT5040U) handy

---

## Dongles & trackers

- [ ] All 3 dongles plugged into PC (prefer same USB ports as before)
- [ ] All 6 trackers powered on
- [ ] SlimeVR Server running
- [ ] SlimeVR shows **6/6 trackers** connected
- [ ] Run `scripts\slimevr-sanity-check.ps1` (READY ✅)

---

## Body parts & straps

- [ ] Body parts assigned: L/R ankles, L/R thighs, waist, chest
- [ ] Straps in usual positions (ankles, thighs, waist, chest)

---

## Software chain

- [ ] Virtual Desktop Streamer running (PC)
- [ ] Quest 3 → Virtual Desktop → same PC
- [ ] SteamVR launched from Virtual Desktop
- [ ] VRChat launched from SteamVR

---

## Calibration

- [ ] SlimeVR **Reset** / **Calibration** done (T-pose)
- [ ] VRChat **Calibrate FBT** done
- [ ] Avatar moves with you; no obvious twist or drift

---

## If something’s wrong

- [ ] Run **Recovery / Fast Reset** (see `slimevr-smolslimes-quest3-setup.md` §11)
- [ ] Optional: run `C:\otel\scripts\slimevr-usb-dongles.ps1` to verify dongles are visible
