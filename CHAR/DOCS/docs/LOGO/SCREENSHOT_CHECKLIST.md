## 🛠 Screenshot Tools & Settings

### Recommended Tools
- **Desktop**: Windows Snipping Tool, Snagit, or Lightshot
- **Mobile**: Browser DevTools device simulation
- **Print**: Browser print preview (Chrome/Firefox)

### Screenshot Settings
- **Resolution**: 1920x1080 for desktop, device-specific for mobile
- **Format**: PNG for transparency, JPEG for file size
- **Quality**: High resolution for documentation clarity
- **File naming**: `dashboard-name_mode_resolution.png`

## 🎨 Screenshot Guidelines

### Quality Standards
- **Clean screenshots**: Close unnecessary tabs/apps
- **Consistent styling**: Use same browser/theme for all shots
- **High contrast**: Ensure logos are clearly visible
- **Proper framing**: Include relevant context around logos

### Brand Consistency
- **Logo positioning**: Verify consistent placement across pages
- **Color accuracy**: Ensure brand colors render correctly
- **Typography**: Check font rendering and sizing
- **Spacing**: Verify proper margins and padding

### Technical Requirements
- **File size**: Optimize for web delivery (< 500KB per image)
- **Dimensions**: Use standard screen resolutions
- **Format**: PNG for transparency, JPEG for photos
- **Metadata**: Include creation date and description
