## 🛠 **Screenshot Tools & Settings**

### **Recommended Tools**
- **Windows**: Snipping Tool, Snagit, or Lightshot
- **Browser**: DevTools device simulation for mobile
- **Print**: Browser print preview (Ctrl+P)

### **Browser Settings**
- **Zoom Level**: 100% (default)
- **Window Size**: Maximized for desktop screenshots
- **Extensions**: Disable for clean screenshots

### **Dark/Light Mode Testing**
- **Windows**: Settings > Personalization > Colors > Choose your mode
- **Browser**: DevTools > Rendering > Emulate CSS prefers-color-scheme
