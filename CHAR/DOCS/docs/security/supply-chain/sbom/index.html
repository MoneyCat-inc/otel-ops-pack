📦 SBOM & Release Attestations

Supply-chain transparency with CycloneDX and sigstore attestations.

What We Provide

  • CycloneDX SBOMs — Complete software bill of materials for all releases
  • Sigstore Attestations — Keyless signing with GitHub OIDC
  • Vulnerability Tracking — Automated scanning and reporting
  • Audit Trail — Every release is signed and verifiable

SBOM Format

We use CycloneDX 1.5 (JSON format) generated via GitHub Actions.

Example SBOM Generation

# In GitHub Actions
- name: Generate SBOM
  uses: anchore/sbom-action@v0
  with:
    format: cyclonedx-json
    output-file: sbom.cyclonedx.json

- name: Sign SBOM
  uses: sigstore/cosign-installer@v3
- run: |
    cosign attest --yes --type cyclonedx \
      --predicate sbom.cyclonedx.json \
      ghcr.io/moneycat-inc/otel-ops-pack:${{ github.sha }}

Verification

# Verify attestation
cosign verify-attestation \
  --type cyclonedx \
  --certificate-identity-regexp=".*" \
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  ghcr.io/moneycat-inc/otel-ops-pack:latest

# Download SBOM
cosign download attestation \
  ghcr.io/moneycat-inc/otel-ops-pack:latest | jq -r '.payload' | base64 -d | jq .
