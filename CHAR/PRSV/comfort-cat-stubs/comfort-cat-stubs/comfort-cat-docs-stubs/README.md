# Comfort Cat Guidelines

Welcome to the **Comfort Cat** creative guidelines for the OTel Observability Kit. This is the single source of truth for all visual, copy, and interaction decisions.

## Quick Start
1. **Read this first** - Overview and philosophy
2. **Check the specs** - Each file covers a specific aspect
3. **Follow the checklist** - Use the PR template to ensure compliance

## Guidelines Structure

### Core Specs
- **`palette.md`** - Color system and theming
- **`type.md`** - Typography hierarchy and usage
- **`motion.md`** - Animation principles and reduce-motion support
- **`copy.md`** - Tone, voice, and CTA guidelines
- **`proofpoints.md`** - Key metrics and success indicators

### Quality Assurance
- **`accessibility.md`** - WCAG compliance and inclusive design
- **`success-criteria.md`** - Definition of done for creative work

## Philosophy

The "Comfort Cat" aesthetic embodies:
- **Calm efficiency** - Like a cat resting beside a softly glowing control board
- **Minimalist precision** - Clean, uncluttered interfaces
- **Gentle motion** - Subtle animations that don't startle
- **Accessible design** - Works for everyone, respects preferences

## Integration

These guidelines are enforced through:
- **PR Template** - Every change must acknowledge compliance
- **CI Checks** - Automated validation of guideline presence
- **Sync Scripts** - Keep Windows and repo copies aligned
- **Cursor Rules** - IDE integration for real-time guidance

## Getting Started

1. **Sync the guidelines**: `npm run comfort:sync`
2. **Check compliance**: `npm run comfort:check`
3. **Start creating**: Follow the specs in each guideline file
