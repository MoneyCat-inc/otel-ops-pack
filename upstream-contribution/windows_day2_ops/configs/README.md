# Windows Day-2 Ops Kit Configuration

This directory contains example configurations for the Windows Day-2 Ops Kit.

## Files

- `otel-collector-config.yaml` - Example OpenTelemetry Collector configuration
- `policy-bundle.json` - Policy bundle configuration
- `fleet-config.json` - Fleet management configuration
- `monitoring-config.json` - Monitoring and alerting configuration

## Usage

Copy these configuration files to your OpenTelemetry Collector deployment and customize as needed for your environment.

## Policy Enforcement

The policy bundle includes:
- Content Security Policy (CSP) enforcement
- Accessibility compliance checking
- Security vulnerability scanning
- Budget and resource limits

## Fleet Management

Configure fleet-wide monitoring with:
- Multi-repository health aggregation
- Composite status reporting
- Cross-platform deployment support
- Automated compliance checking
