# Visual Assets Specification - ECRR v1.0.0 Launch

**Release Date:** January 21, 2025  
**Brand:** Resonai  
**Tone:** Professional, accessible, affirming  
**Style:** Clean, modern, inclusive

---

## 🎨 **Brand Guidelines**

### **Color Palette**
- **Primary**: #7C5CFF (Purple - tech innovation)
- **Secondary**: #00D4AA (Teal - accessibility/trust)
- **Accent**: #FF6B6B (Coral - affirming/energetic)
- **Neutral**: #2D3748 (Dark gray - professional)
- **Background**: #FFFFFF (White - clean/accessible)
- **Text**: #1A202C (Dark - high contrast)

### **Typography**
- **Headings**: Inter Bold (accessible, modern)
- **Body**: Inter Regular (readable, inclusive)
- **Accent**: Inter Medium (emphasis without overwhelming)

### **Visual Style**
- **Clean lines** and **generous whitespace**
- **Rounded corners** (8px radius) for friendly feel
- **High contrast** for accessibility
- **Inclusive imagery** (diverse representation)
- **Minimal text** on images (key messages only)

## 📐 **Technical Specifications**

### **File Formats**
- **Images**: PNG (for transparency) or JPG (for photos)
- **Icons**: SVG (scalable) or PNG (for complex designs)
- **Video**: MP4 (H.264 codec, 30fps)

### **Resolution Requirements**
- **Twitter/X**: 1200x675px (1.78:1 ratio)
- **LinkedIn**: 1200x627px (1.91:1 ratio)
- **Instagram Story**: 1080x1920px (9:16 ratio)
- **Bluesky**: 1200x630px (1.91:1 ratio)
- **YouTube Thumbnail**: 1280x720px (16:9 ratio)
- **Email**: 600px width (responsive height)

### **Accessibility Requirements**
- **Color contrast**: Minimum 4.5:1 for normal text, 3:1 for large text
- **Alt text**: Descriptive alt text for all images
- **Text size**: Minimum 16px for body text, 24px for headings
- **Focus indicators**: Visible focus states for interactive elements
