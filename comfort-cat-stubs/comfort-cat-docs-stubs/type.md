# Comfort Cat Typography

## Font Stack
- **Primary**: Inter, system-ui, sans-serif
- **Monospace**: JetBrains Mono, 'Courier New', monospace
- **Fallback**: Arial, sans-serif

## Hierarchy

### Headings
- **H1**: 2.25rem (36px) / 2.5rem line-height / 700 weight
- **H2**: 1.875rem (30px) / 2.25rem line-height / 600 weight
- **H3**: 1.5rem (24px) / 2rem line-height / 600 weight
- **H4**: 1.25rem (20px) / 1.75rem line-height / 500 weight

### Body Text
- **Large**: 1.125rem (18px) / 1.75rem line-height / 400 weight
- **Base**: 1rem (16px) / 1.5rem line-height / 400 weight
- **Small**: 0.875rem (14px) / 1.25rem line-height / 400 weight

### Code & Data
- **Code**: 0.875rem (14px) / 1.25rem line-height / 500 weight
- **Metrics**: 1.125rem (18px) / 1.25rem line-height / 600 weight
- **Timestamps**: 0.75rem (12px) / 1rem line-height / 400 weight

## Usage Guidelines
- Use H1 only for page titles
- H2 for major sections
- H3 for subsections
- H4 for card titles
- Code font for all technical data, metrics, and timestamps
- Maintain consistent line heights for readability

## Accessibility
- Minimum 4.5:1 contrast ratio for normal text
- Minimum 3:1 contrast ratio for large text
- Use relative units (rem) for scalability
- Respect user font size preferences
