# Comfort Cat Palette

## Primary Colors
- **Cat Nap Blue**: `#0ea5e9` - Primary brand color, calm and trustworthy
- **Midnight**: `#0c4a6e` - Deep background, like a cat's shadow
- **Dawn**: `#f0f9ff` - Light background, soft and welcoming

## Accent Colors
- **Success Green**: `#10b981` - Healthy status, like fresh grass
- **Warning Amber**: `#f59e0b` - Gentle alerts, like a cat's eyes
- **Error Red**: `#ef4444` - Critical issues, like a cat's alert ears

## Neutral Palette
- **Gray 900**: `#111827` - Primary text
- **Gray 700**: `#374151` - Secondary text
- **Gray 500**: `#6b7280` - Muted text
- **Gray 300**: `#d1d5db` - Borders and dividers

## Usage Guidelines
- Use Cat Nap Blue for primary actions and key metrics
- Keep backgrounds dark (Midnight) for the control room aesthetic
- Use success/warning/error colors sparingly, only for status
- Maintain high contrast ratios for accessibility

## Dark Mode First
This palette is designed for dark mode by default, reflecting the "control room" aesthetic where the cat naps beside softly glowing displays.
